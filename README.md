## How it works
This script automatically install [Windwows Terminal latest](https://github.com/microsoft/terminal/releases/latest) on pc, then isntall [Python 3.10.0](https://www.python.org/downloads/release/python-310), then install [Git latest](https://github.com/git-for-windows/git/releases/latest)

# 🚀 Installation
```bash
cls && curl -sL https://raw.githubusercontent.com/OxFF00FF/wt-autoinstall-windows10/main/wt_py3100_git.bat -o "%TEMP%\wt_install.bat" && call "%TEMP%\wt_install.bat" && del "%TEMP%\wt_install.bat"
```
